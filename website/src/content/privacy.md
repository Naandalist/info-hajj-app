# Kebijakan Privasi

## 1. Pendahuluan

Kebijakan privasi ini menjelaskan bagaimana kami menangani informasi dalam aplikasi **Info Haji**. Aplikasi dapat digunakan secara gratis; biaya pengembangan dan operasional sebagian didukung oleh iklan. Kami berkomitmen untuk melindungi privasi Anda dengan tidak mengumpulkan data pribadi ke server pengembang.

Aplikasi menampilkan iklan melalui **Google AdMob** (Google LLC). Google dapat memproses data terbatas terkait iklan sebagaimana dijelaskan pada bagian 4.

## 2. Prinsip Dasar Privasi

### 2.1 Tidak Ada Pengumpulan Data Pribadi ke Server Pengembang
- Kami tidak mengumpulkan, menyimpan, atau memproses data pribadi Anda di server pengembang
- Aplikasi tidak memerlukan registrasi atau login
- Kami tidak membangun profil pengguna di sisi pengembang, dan tidak menjual data kepada pihak ketiga

### 2.2 Data yang Disimpan Secara Lokal di Perangkat
- Versi saat ini tidak menyimpan riwayat pencarian nomor porsi atau data pribadi di perangkat Anda
- Pengaturan tampilan atau preferensi sederhana (jika ada) hanya berlaku selama aplikasi digunakan dan tidak dikirim ke server pengembang.
- Anda dapat menghapus seluruh data lokal dengan menghapus/uninstal aplikasi dari perangkat.

## 3. Koneksi Server

### 3.1 Pengambilan Konten
- Aplikasi terhubung ke server untuk mengambil informasi haji seperti data porsi, estimasi keberangkatan, dan berita haji terkini
- Ketika Anda mencari nomor porsi, aplikasi mengirimkan nomor tersebut ke server untuk mendapatkan informasi terkait
- Kami tidak menyimpan atau mencatat nomor porsi yang Anda cari
- Aplikasi juga meminta dan menampilkan iklan melalui Google AdMob

### 3.2 Tidak Ada Logging Data User di Server Pengembang
- Server pengembang tidak menyimpan data request dari pengguna
- Tidak ada pencatatan aktivitas atau perilaku pengguna di sisi pengembang
- Data terkait iklan diproses oleh Google, bukan oleh server pengembang. Lihat bagian 4

## 4. Iklan

### 4.1 Penayangan Iklan
Beberapa layar aplikasi menampilkan iklan dari **Google AdMob** (Google LLC), yaitu:
- Daftar berita di beranda (iklan tampil di antara beberapa berita)
- Halaman detail berita

Iklan yang tampil diberi label sebagai iklan dan tidak menyamar sebagai berita atau konten aplikasi. Jenis dan penempatan iklan dapat berubah seiring pembaruan aplikasi.

### 4.2 Data yang Diproses oleh Google
Untuk menayangkan, mengukur, membatasi frekuensi, dan (jika diizinkan) mempersonalisasi iklan, Google dapat memproses:
- Pengenal iklan perangkat (Android Advertising ID atau iOS IDFA bila diizinkan)
- Alamat IP dan perkiraan lokasi umum yang diturunkan dari alamat IP
- Informasi perangkat dan aplikasi (jenis perangkat, sistem operasi, versi aplikasi, bahasa)
- Interaksi dengan iklan (tayangan, klik, dan pengukuran kinerja iklan)

Data tersebut diproses oleh Google sesuai kebijakan privasi Google. Kami tidak menerima data mentah tersebut, dan tidak menggunakannya untuk membangun profil pengguna.

### 4.3 Persetujuan dan Pengaturan Iklan
- Di wilayah yang mewajibkan persetujuan (misalnya EEA, Inggris, dan Swiss), formulir persetujuan Google dapat muncul sebelum iklan diminta. Iklan hanya diminta setelah persetujuan yang berlaku mengizinkan.
- Di iOS, sistem dapat menampilkan permintaan izin **App Tracking Transparency** sebelum pengenal iklan digunakan untuk pelacakan. Jika Anda menolak, iklan tetap dapat tampil namun dibatasi dan tidak dipersonalisasi menggunakan IDFA.
- Anda dapat mengatur atau menarik preferensi iklan kapan saja melalui pengaturan perangkat:
  - **Android:** Setelan → Google → Iklan (hapus/reset ID iklan atau nonaktifkan personalisasi iklan)
  - **iOS:** Setelan → Privasi & Keamanan → Pelacakan (matikan "Izinkan Aplikasi Meminta untuk Melacak") dan Setelan → Privasi & Keamanan → Apple Advertising
  - **Google:** [Setelan Iklan Google](https://adssettings.google.com/)

### 4.4 Batasan dari Sisi Pengembang
- Pengembang tidak mengoperasikan server iklan sendiri
- Pengembang tidak mengirimkan nomor porsi haji, kata kunci pencarian, atau identitas Anda kepada Google untuk penargetan iklan
- Pengembang tidak menerima salinan data iklan atau daftar pengguna dari Google
- Mengetuk iklan membuka tujuan pengiklan melalui Google. Tombol pada iklan (misalnya "Instal") mengarah ke halaman pengiklan dan bukan pemasang aplikasi di dalam **Info Haji**.

### 4.5 Tautan Pihak Ketiga
- [Kebijakan Privasi Google](https://policies.google.com/privacy)
- [Cara Google menggunakan data dari aplikasi yang menggunakan layanannya](https://policies.google.com/technologies/partner-sites)
- [Iklan dan data Google](https://policies.google.com/technologies/ads)

## 5. Jenis Data yang TIDAK Kami Kumpulkan

Pengembang TIDAK mengumpulkan:
- Informasi identitas pribadi (nama, email, nomor telepon)
- Nomor porsi haji yang Anda cari atau hasil pencarian Anda
- Lokasi GPS atau data lokasi presisi
- Riwayat penggunaan aplikasi secara detail ke server pengembang
- Data demografis atau profil pengguna
- Informasi kontak atau media sosial
- Informasi pembayaran atau data keuangan

## 6. Hak Pengguna

### 6.1 Tidak Ada Akun
- Aplikasi tidak memerlukan pembuatan akun atau login
- Tidak ada proses "penghapusan akun" karena tidak ada akun yang dibuat
- Anda dapat menggunakan aplikasi secara anonim

### 6.2 Kontrol atas Iklan dan Data Lokal
- Anda dapat membatasi atau menonaktifkan personalisasi iklan melalui pengaturan perangkat dan Setelan Iklan Google sebagaimana dijelaskan pada bagian 4.3
- Anda dapat menghapus data lokal dengan menghapus/uninstal aplikasi dari perangkat
- Untuk data yang diproses Google terkait iklan, Anda dapat menggunakan kontrol dan hak yang dijelaskan dalam [Kebijakan Privasi Google](https://policies.google.com/privacy)

### 6.3 Transparansi
- Kami berkomitmen untuk transparansi penuh mengenai cara aplikasi bekerja dan data apa saja yang digunakan
- Tidak ada "data tersembunyi" yang dikumpulkan tanpa sepengetahuan Anda di luar yang telah dijelaskan dalam kebijakan ini

## 7. Teknologi yang Digunakan

### 7.1 Koneksi Internet
- Internet digunakan untuk mengambil informasi haji (data porsi, estimasi keberangkatan, berita haji) dan untuk memuat iklan
- Koneksi diperlukan untuk mendapatkan data terkini dari sistem informasi haji
- Tanpa koneksi internet, fitur yang bergantung pada server dan penayangan iklan mungkin tidak berfungsi, tetapi konten yang sudah dimuat tetap dapat dibaca

### 7.2 SDK Pihak Ketiga
- Aplikasi menggunakan **Google Mobile Ads SDK** (AdMob) untuk menampilkan iklan dan **Google User Messaging Platform** untuk formulir persetujuan iklan
- Pengembang tidak memasang SDK analytics pihak ketiga terpisah yang mengumpulkan data pribadi pengguna ke server pengembang

## 8. Anak-Anak

Aplikasi **Info Haji** ditujukan untuk pengguna umum dan tidak dirancang khusus untuk anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi anak-anak ke server pengembang. Iklan ditayangkan oleh Google sesuai kebijakan Google. Jika Anda adalah orang tua atau wali dan memiliki pertanyaan, silakan hubungi kami melalui kontak pada bagian 10.

## 9. Perubahan Kebijakan

### 9.1 Komitmen Berkelanjutan
- Kami berkomitmen untuk menjaga prinsip minimasi data: hanya mengambil dan menggunakan data yang benar-benar diperlukan untuk menjalankan fungsi aplikasi
- Pengembang tidak mengumpulkan data pribadi ke server pengembang dan berupaya mempertahankan prinsip ini ke depannya

### 9.2 Notifikasi Perubahan
- Jika di masa mendatang terdapat perubahan kebijakan privasi yang signifikan, kami akan menyampaikan informasi perubahan tersebut melalui pembaruan aplikasi atau pemberitahuan yang jelas di dalam aplikasi
- Pengguna akan diberitahu sebelum ada perubahan yang mempengaruhi privasi
